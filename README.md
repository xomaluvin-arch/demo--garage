# GARAGE 47 — демонстрационный сайт автосервиса

Многостраничный frontend-проект на React + Vite. Используется HashRouter, поэтому переходы и обновление страниц работают на GitHub Pages без отдельной настройки сервера.

## Страницы
- `#/` — главная
- `#/services` — услуги и цены
- `#/reviews` — демонстрационные отзывы
- `#/contacts` — контакты, карта и форма записи

## Запуск
1. Установить Node.js LTS.
2. В терминале открыть папку проекта.
3. Выполнить `npm install`.
4. Выполнить `npm run dev`.
5. Открыть адрес, который покажет Vite (обычно `http://localhost:5173`).

## Сборка для публикации
`npm run build` — готовый сайт появится в папке `dist`.

## Демо-база данных
Файл `src/data/database.js` содержит начальные услуги и отзывы. Заявки из формы сохраняются в `localStorage` браузера. Это локальное хранилище для демонстрации, а не полноценная общая серверная БД: данные доступны только в том браузере и на том устройстве, где была отправлена форма.

## Перед показом реальному клиенту
Заменить вымышленные телефон, адрес, почту, цены, отзывы и координаты карты на подтверждённые данные. Все показатели и отзывы сейчас демонстрационные. Карта использует встраиваемую карту OpenStreetMap без API-ключа; если сторонний сервис временно недоступен, ссылка «Открыть карту отдельно» ведёт на карту в новой вкладке.
